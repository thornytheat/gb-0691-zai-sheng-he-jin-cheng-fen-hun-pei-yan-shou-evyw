# 数据定义

元素质量按物料净重×含量汇总；干湿基转换，低于检出限给上下界，不可把未检出当零，配方版本锁定。

输入字段：lot, batch, mass, unit, moisture, element, assay, basis, revision。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

Cu和Zn目标区间为V1教学配方，不外推为生产工艺。缺测元素贡献范围按0–100%计；湿基换干基先除以干物质比例；样例存在只测单元素的料批，因此验收可能待补测。

混配按batch炉次独立计算；同一lot可在不同炉次出现，采信键为(batch,lot,element)，移除批次的试算也仅影响所属炉次。

## 追溯召回

复配转移记录字段：from_batch, to_batch, lot, mass（kg，大于零）。表头可调序不得缺列或重复；转出炉次与转入炉次相同、重量非正、列数不符的行进隔离并保留行号与原因码，相同转移计重复。转移记录不参与混配计算，仅描述炉次间物料流向。

污染传播：批号直接投料的炉次为起点（以来料采信记录为证，含原始行号）；沾料炉次的转出转移使转入炉次沾料（复配转入），逐级传播，环路由已访集合截断。遍历按炉次排序，结果确定。

炉次处置三档：验收不合格（区间超出限值）→召回并生成召回单；验收待补测或无验收结论（仅有成分区间、沾料记录未进入验收）→冻结待复测，不得当作合格；各元素区间均在限值内→可以留用。判断依据逐炉记录区间、限值与验收结论，并快照验收批次的签核状态（decision、revision、run_id、规则版本）；已签核批次的证据CSV仍可按run_id追回。

追溯键=追溯规则版本+run_id+批号+转移记录SHA256，重跑复用原追溯。每处理一炉提交一次检查点（状态与召回单同事务），中断后续跑从frontier继续；召回单按(trace_id,炉次)唯一，单号为两者摘要，重跑与续跑均不重复生成。
